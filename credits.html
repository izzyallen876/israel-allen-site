Everything on this site was written by hand with no frameworks, no libraries and no web fonts. The only things I didn’t make are two images in the lab, described below.

Made with

  • Plain HTML, CSS and JavaScript. WebGL is used directly, with no 3D library.
  • No package dependencies, no build step and no requests to other sites.
  • The code is on GitHub at github.com/izzyallen876 under the MIT License.

Type

There are no font files. Text uses the monospace font already on your device, such as SF Mono, Menlo, Consolas or DejaVu Sans Mono, so no font licenses are involved.

Art and film

The crystal, the helmet, the reaching hands and the film are all drawn live by code in the repository. The film’s sound is synthesised in your browser with the Web Audio API. There are no audio files.

The look draws on risograph prints, collage, magic-realist painting, woodblock-style landscapes and Y2K sticker-pack packaging. These were influences only. No artwork, lettering or photograph from any of them is used here. The sky, sun, road and tower in the home page header are drawn by code.

The gongfu tea timer under /apps/tea/ is my own work and uses the same MIT license as the rest of the code.

Images

  • thermal-street.jpg is a thermal-style street image with detection boxes. It appears in the lab only.
  • pixel-portrait.jpg is a pixelated portrait in offset colors. It appears in the lab only.
  • The card artwork on the home page is drawn in CSS, and the social preview image is a screenshot of this site’s own code.
