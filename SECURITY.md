# Security

This is a static website. It has no server code, no accounts, no database and no stored visitor data, so the attack surface is small.

If you find a problem, such as a flaw in the code or a link that points somewhere harmful, please email israel.l.allen.28@dartmouth.edu with the details. I'll look at it promptly. Please don't open a public issue for something that could put visitors at risk.
