## What "license or permission" has to say

Writing "found online" is not a license. For each image you need one of:

- you made it, so write "Own work";
- the creator gave you written permission to use it on a public website, so link or attach it;
- it is under a license that allows this use, such as Creative Commons or a public-domain dedication, so name the license and keep any credit it requires.

If the portrait shows a real, identifiable person, make sure the permission also covers use of their likeness.

If you can't fill in a row, replace the image. Put a new file in `assets/img/` under the same name and the site will use it. The credits page already points people here.
